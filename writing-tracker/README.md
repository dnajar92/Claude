# Daily Word Count

A one-page tracker for logging whether you wrote each day and how many words.

- **Log writing**: add a session's words (they add up across the day) or set a day's total. Leave the count blank to mark a day as written without a number.
- **Daily goal** with a progress bar, plus current and longest streaks, this month's words and an all-time total.
- **26-week calendar** shaded by how close each day came to the goal, and a **30-day bar chart** with the goal line. Click any day to edit it.

Open `index.html` in a browser to use it locally (entries are saved in that browser's local storage). The published Claude artifact version saves entries to your account instead.
